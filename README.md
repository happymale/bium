# 비움 BIUM

> 버리는 법을 몰라서, 아직 집에 있습니다.

사진 한 장으로 폐기물 배출 방법을 판별해주는 모바일 웹앱.
「신인류 AI 사피엔스 경험디자인」 기말 팀프로젝트.

사람들은 쓰레기를 못 들고 나가는 게 아니라 **어떻게 버리는지 몰라서** 못 버립니다.
비움은 그 판단을 30초로 줄입니다.

---

## 무엇을 하는가

물건 사진을 찍으면 AI가 **재질과 부착물**을 보고 네 경로 중 하나로 분류합니다.

| 경로 | 설명 | 비용 |
|---|---|---|
| 🟢 재사용·기부 | 아직 쓸 만한 가구·의류·장난감 | 0원 (방문 픽업) |
| 🔵 무상 방문수거 | 폐가전 전 품목 | 0원 |
| 🟠 대형폐기물 신고 | 가구·매트리스 등 | 지자체 요금표 |
| 🔴 전용 수거함 | 폐건전지·폐의약품·형광등 | 0원 |

**종량제봉투는 네 경로 어디에도 없습니다.** 이 앱의 목표는 "대신 버려주기"가 아니라 **종량제로 가는 물건을 줄이는 것**입니다.

## 설계 원칙

- **AI에게 금액을 묻지 않습니다.** AI는 품목·경로·근거만 판단하고, 수수료는 항상 서대문구 실제 고시 요금표(218행)에서 조회합니다. 모델이 요금을 지어내는 사고가 구조적으로 불가능합니다.
- **확신이 없으면 없다고 말합니다.** 확신도 85% 미만이면 결과를 확정하지 않고 구청 문의로 안내합니다.
- **재사용을 기본값으로 둡니다.** 서비스가 편해질수록 사람은 더 버리기 때문입니다.
- **대표 지표는 "버린 개수"가 아니라 "다시 쓰이게 된 비율"입니다.**

디자인 시스템 명세는 [DESIGN.md](DESIGN.md) 를 보세요.

## 실행

### 1. 의존성 설치

```bash
npm install
```

Node.js 20 이상이 필요합니다.

### 2. 환경변수 설정

`.env.local.example` 을 `.env.local` 로 복사하고 값을 채웁니다.

```bash
cp .env.local.example .env.local
```

| 변수 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 아니오 | [console.anthropic.com](https://console.anthropic.com) 에서 발급. **없으면 목업 응답으로 동작**합니다. |
| `BIUM_MODEL` | 아니오 | 판별 모델. 미설정 시 `claude-opus-5` |
| `VITE_GA_MEASUREMENT_ID` | 아니오 | GA4 측정 ID. 비우면 GA 완전 비활성 |

**모델별 비용 (사진 1장당)**

| 모델 | 대략 비용 | 용도 |
|---|---|---|
| `claude-haiku-4-5` | 약 7원 | 개발·테스트 |
| `claude-sonnet-5` | 약 27원 | 균형 |
| `claude-opus-5` | 약 45원 | 발표·실사용 (기본값) |

> ⚠️ `.env.local` 은 `.gitignore` 에 등록돼 있습니다. **절대 커밋하지 마세요.**
> API 키가 유출되면 타인이 여러분의 크레딧을 씁니다.

### 3. 개발 서버

```bash
npm run dev
```

http://localhost:5173

### 4. 프로덕션 빌드

```bash
npm run build
```

## 구조

```
├─ bium_mockup_1.html      원본 화면 목업 (발표 자료)
├─ DESIGN.md               디자인 시스템 명세 (AI 에이전트용)
├─ server/                 서버 전용 — API 키가 여기서만 읽힙니다
│  ├─ prompt.ts            판별 프롬프트 + 출력 스키마
│  ├─ classify.ts          Claude Vision 호출 + 목업 폴백
│  └─ vitePlugin.ts        dev 서버의 /api/classify 미들웨어
└─ src/
   ├─ data/
   │  ├─ routeKinds.ts     4개 처리 경로 정의
   │  ├─ sdmBulkFees.ts    서대문구 대형폐기물 요금표 218행 (실제 고시값)
   │  └─ region.ts         지역 규정·전화번호
   ├─ lib/
   │  ├─ fees.ts           요금 조회 (표기 별칭 + 규격 매칭)
   │  ├─ classify.ts       판별 요청 + 요금표 병합
   │  ├─ image.ts          업로드 전 리사이즈 (긴 변 1024px)
   │  ├─ korean.ts         조사 자동 선택 (은/는, 이/가)
   │  ├─ report.ts         리포트 집계
   │  └─ analytics.ts      GA4 (동의 전 스크립트 미로드)
   ├─ screens/             홈 · 목록 · 촬영 · 판별결과 · 신청대행 · 리포트 · 설정
   ├─ store/               zustand + localStorage
   └─ styles/tokens.css    디자인 토큰 (라이트/다크)
```

### API 키가 브라우저로 나가지 않는 이유

키는 `server/` 안에서만 읽히고, 클라이언트는 `/api/classify` 로 이미지를 보낼 뿐입니다.
빌드 산출물에 `anthropic`·`sk-ant`·프롬프트 문자열이 포함되지 않는 것을 확인했습니다.
